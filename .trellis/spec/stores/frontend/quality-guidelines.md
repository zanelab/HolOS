# @vben/stores Quality Guidelines

> Strict-mode TS, setup-style stores.

## Style

- 4 spaces TS, single quotes, no any

## Naming

| Thing | Convention |
|---|---|
| Store hook | useXxxStore |
| State | camelCase |
| Action | verb + noun |

## Forbidden

- Don't use Options API
- Don't put APIs in store factories
